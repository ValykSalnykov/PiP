# DAO Tools+ Chrome Web Store Submission

## Короткое описание

```text
Инструменты DAO для Planfix и Syrve: PiP на внутренних страницах, автологин и проверка серверов.
```

## Полное описание

```text
DAO Tools+ — внутреннее рабочее расширение компании DAO для сотрудников и подрядчиков, которые работают с DAO Planfix, Syrve и внутренними DAO веб-сервисами.

Расширение объединяет несколько рабочих сценариев в одном интерфейсе:
- добавляет в DAO Planfix кнопки и статусы для быстрого входа в backoffice Syrve, открытия служебных страниц, проверки доступности сервера и проверки статуса лицензий;
- открывает рабочие страницы Syrve и автоматически подставляет выданные компанией учетные данные только для согласованного пользователя и одобренного устройства;
- получает открытый период из служебной страницы Syrve и возвращает результат в интерфейс Planfix;
- запускает встроенный интерактивный Picture-in-Picture на внутренних DAO веб-страницах на доменах hub.daolog.net и *.us-central1.hosted.app;
- хранит локальные настройки пользователя и состояние доступа устройства, чтобы не требовать повторного ввода при каждом запуске.

Расширение предназначено только для внутренних рабочих задач DAO. Оно не предназначено для общего веб-серфинга, не внедряет удаленный код и не изменяет поведение сайтов вне перечисленных рабочих доменов.
```

## URL главной страницы

```text
https://syrve.daolog.net/
```

## Единственное назначение

```text
Обеспечивать сотрудникам DAO единый рабочий поток между Planfix, Syrve и внутренними DAO веб-сервисами: запуск служебных страниц, авторизация, проверка состояния сервера и лицензий, а также интерактивный Picture-in-Picture на внутренних страницах DAO.
```

## Обоснование разрешений

### tabs

```text
Разрешение tabs используется для рабочих сценариев внутри DAO Tools+: расширение открывает и закрывает служебные вкладки Syrve, получает текущую активную вкладку для переключения Picture-in-Picture, отправляет сообщения между service worker и content scripts, а также обновляет состояние badge для PiP.
```

### storage

```text
Разрешение storage используется для локального хранения рабочих настроек и состояния доступа устройства: User ID, уникального client ID устройства, request ID, персонального extension key, последнего выбранного адреса сервера и пользовательского флага discoMode. Это нужно, чтобы не требовать повторного ввода и сохранять рабочий контекст между сеансами.
```

## Обоснование доступа к хостам

### https://dao.planfix.ua/*

```text
На страницах DAO Planfix расширение добавляет рабочие кнопки, читает адрес сервера и порт из конкретных полей карточек, показывает статусы доступности сервера, ошибки и результаты проверки лицензий, а также запускает связанные рабочие действия пользователя.
```

### https://*.syrve.online/resto* , https://*.daocloud.it/resto* , http://*.daocloud.fun/resto* , https://*.daocloud.fun/resto*

```text
На страницах Syrve расширение открывает нужные рабочие разделы, автоматически подставляет выданные DAO учетные данные в форму входа и читает значение открытого периода со служебной страницы health.jsp после явного действия пользователя из интерфейса расширения.
```

### https://*.us-central1.hosted.app/* и https://hub.daolog.net/*

```text
На внутренних DAO веб-страницах расширение внедряет локально упакованный PiP-контроллер и CSS-ресурсы из пакета расширения, чтобы включать и выключать интерактивный режим Picture-in-Picture. Удаленный код на этих доменах не загружается.
```

### https://planfix-to-syrve.com:8000/*

```text
Этот backend принимает рабочие запросы от popup и Planfix-сценариев: адрес сервера, порт и User ID для запуска backoffice-потока, получение последней ошибки, получение описания режима и переключение режима.
```

### http://daologistics.duckdns.org:8100/*

```text
Этот внутренний DAO backend используется для согласования доступа устройства и защищенных рабочих операций: запрос доступа устройства, активация extension key по коду подтверждения, выдача учетных данных Syrve для одобренного пользователя и устройства, проверка доступности сервера и проверка лицензий.
```

## Удаленный код

```text
Нет. Все JavaScript- и CSS-файлы, которые выполняет расширение, поставляются внутри пакета расширения. Сетевые ответы от backend-сервисов используются только как данные JSON и не выполняются как код.
```

## Что расширение реально обрабатывает

```text
- локально хранит User ID, client ID устройства, request ID, extension key, last server context и discoMode;
- отправляет на DAO backend User ID, client ID устройства, request ID, claim code, extension key, адрес сервера и порт;
- получает с DAO backend логин и пароль Syrve для одобренного пользователя и устройства и подставляет их в форму авторизации Syrve;
- читает из Planfix только те поля карточек, которые нужны для рабочих действий с сервером;
- читает со служебной страницы Syrve значение открытого периода и возвращает его в интерфейс Planfix.
```

## Технический блокер для ревью

```text
Сейчас внутренний DAO backend http://daologistics.duckdns.org:8100 отвечает только по обычному HTTP. Через него идут request/claim потоки, extension key и выдача учетных данных Syrve. Это реальный риск отклонения на ревью, потому что текст описания не компенсирует передачу чувствительных данных без современного HTTPS/TLS. Для надежного прохождения проверки этот backend нужно перевести на HTTPS с поддержкой актуального TLS, а затем обновить URL в manifest.json и background.js.
```
